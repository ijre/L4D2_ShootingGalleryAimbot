# Hello! This is a fun little SourceMod plugin that gives you aimbot for the Shooting Gallery in Dark Carnival.

### **IMPORTANT NOTE**: When the plugin fires for the player, it will make no sound. While this is an unfixable problem *directly*, it can be worked around by simply manually playing the sound, which still syncs up decently at ~200 ping. However, actually doing this properly requires a lot of manual work that I simply don't want to do right now.

#### Get the most recent build [here](https://github.com/ijre/L4D2_ShootingGalleryAimbot/releases/latest)!
